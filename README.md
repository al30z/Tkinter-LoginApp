# 🧩 Tkinter Login–Signup GUI Application

A simple **Login and Signup GUI application** built using **Python’s Tkinter library**.  
It provides user authentication, form validation, and file-based credential storage — perfect for learning GUI design and basic user management in Python.

---

## 🚀 Features

- **Login Page**
  - Username & masked password fields  
  - Validation for empty inputs and invalid credentials  
  - Message boxes for login success or failure  

- **Signup Page**
  - New Username, Password, Confirm Password fields  
  - Validation for empty fields and password mismatch  
  - Prevents duplicate usernames  
  - Returns to login page after successful registration  

- **Data Storage**
  - Credentials stored locally in a simple text file (`users.txt`)  
  - Each record: `username,password`
